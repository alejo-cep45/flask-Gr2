# flask-Gr2

Para ejecutar el archivo primero vamos a crear el entorno virtual de python con: ```python -m venv .venv```

Despues ejecutamos el entorno virtual con: ```.\.venv\Scripts\activate```

Para la aplicacion de to-do solo es necesario ejectuar: ```python '.\to-do list\to-do.py'```

Para la aplicacion de flask, vamos a descargar los requerimientos del progarma guardados en requirements con: ```pip install -r '.\aplicacion flask\requirements.txt' ```

Para ejecutar el programa ejecutamos lo siguiente: ```python '.\aplicacion flask\app.py'```


En la linea de comandos nos dara un link al cual accederemos con ctrl+click

Luego en la barra del navegador al final agregamos "/inicio" para ver la pantalla de bienvenida
